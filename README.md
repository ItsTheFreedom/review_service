# Система модерации отзывов

Микросервис для сбора отзывов и их проверки модераторами через Telegram. API и Telegram-бот работают параллельно в едином асинхронном процессе.

## 1. Запуск проекта
Установите зависимости проекта:
```bash
pip install -r requirements.txt
```
Запустите единую точку входа:
```bash
python main.py
```
*(В консоли отобразится старт uvicorn и сообщение об успешном подключении бота).*

## 2. Авторизация модератора
Чтобы система знала, кому маршрутизировать новые отзывы, необходимо зарегистрировать ваш Telegram ID в базе данных.
1. Откройте Telegram-бота и отправьте команду `/start`. Бот пришлет ваш уникальный Telegram ID.
2. Откройте интерактивную документацию API (Swagger) в браузере по адресу: 👉 http://127.0.0.1:8000 (настроен автоматический редирект на `/docs`).
3. В блоке «Модераторы» выберите метод `POST /moderators/` -> нажмите **Try it out**.
4. Вставьте полученный Telegram ID в поле `telegram_id` и нажмите **Execute**.

## 3. Работа с отзывами
* **Имитация отзыва:** В Swagger откройте метод `POST /reviews/` -> **Try it out**. Заполните тело запроса (оценка от 1 до 5, параметр `is_buyer` и т.д.) и нажмите **Execute**. Отзыв попадет в БД со статусом `pending`.
* **Модерация:** В Telegram моментально поступит уведомление о новом отзыве с inline-кнопками. Нажмите **«Одобрить»** или **«Отклонить»**. Бот обновит сообщение и изменит статус отзыва в базе данных.
* **Проверка результата:** Выполните в API метод `GET /reviews/approved` (список всех одобренных) или `GET /reviews/{review_id}` (детали конкретного отзыва).

## 4. Дополнительный функционал
В меню бота предусмотрена кнопка **«⏸ Остановить отзывы»**. При ее нажатии статус модератора в БД (`is_receiving`) меняется на `False`, и API временно прекращает маршрутизацию новых отзывов на этот аккаунт.
